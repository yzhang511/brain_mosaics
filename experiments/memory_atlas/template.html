Projection details

Key PCA uses centered unit-normalized stored keys. Value PCA uses centered projected values with head output scale, in the residual space. Exact thin-QR reduction preserves projected-value distances before PCA. PCA axes are fitted separately per head; axis positions are not comparable across heads. Shared output-projection bias is not assigned to slots. Profiles rank token directions by cosine alignment; raw dot products are also shown. These omit downstream layers and final layer normalization. Candidate-direction alignment uses only the first candidate token at the final prompt position; behavioral D scores use complete continuations.

Methods and validation

Six examples span five animals and were selected for behavioral success. This atlas is exploratory. Small answer margins and presentation effects limit interpretation. No parameters were edited and no causal interventions were performed. Positive direct alignment does not establish support for a candidate in the full model.

Numeric files: atlas.json, arrays.npz, heads.csv, baselines.csv, validation.csv, metadata.json. See the accompanying report for interpretation.
